# Observable coordinate maps

`tools.semantic_checks` contains an experimental checker helper for comparing complete finite Bool or Int output relations whose coordinate layouts differ. The current qualification is limited to one CP-Bench 056 N-Queens mapping: the reference vector maps to the first column of the candidate matrix, and every omitted candidate cell has a declared reconstruction literal. The qualified reference SMT-LIB SHA-256 is `b0c936b2aadd675483499f31c6ff6331c378a400bd0344e0d0e1fadf9f7ed8c3`; the candidate SMT-LIB SHA-256 is `8c8d3a08cda149142e1422aaaf831835e5127e9633f4fb644b8e763056b4a69e`; the coordinate-map JSON SHA-256 is `9a570d3aef5703233b45c0de559542278c04dfa28891afc1468b977e391806f9`. These pins identify that one qualification fixture only; they do not establish support for another instance or language.

The caller owns the source trust boundary. Before parsing either model, it must verify the exact full reference and candidate SMT-LIB source hashes against trusted run provenance, then pass every assertion from each parsed model to the helper. The helper fingerprints the ordered assertion lists it receives, but cannot detect that its caller supplied an incomplete list or unpinned SMT source. Keep the source hashes and the complete assertion extraction receipt with the equivalence result.

Only equal Bool-to-Bool or Int-to-Int coordinate sorts are accepted. Bool/Int normalization, objectives, and inferred coordinate layouts are outside this helper's scope. Every reference coordinate must map exactly once. Each unmapped candidate coordinate must have one typed reconstruction value, and the helper proves each obligation with `UNSAT(candidate_assertions ∧ candidate_cell != reconstruction_value)` before it issues a verified-map receipt. A failed or unknown proof is a typed refusal; it must remain unresolved.

After proof, fresh aliases expose every mapped coordinate to both projections. Candidate projection also bridges every reconstructed coordinate, preserving all candidate assertions, and existentially hides only those private aliases afterward. Compare the resulting formulas as full relations. Matching SAT/UNSAT status alone is insufficient. The default reconstruction query timeout is 5 seconds; timeout and solver `unknown` both refuse qualification.

Z3Py is imported lazily by helper functions, so importing `tools.semantic_checks` does not make Z3 a required dependency for unrelated project tools. Calling the map/projection functions requires a compatible Z3Py installation.
